# frknaydn.lol

Kişisel portfolyo sitem. Tek sayfa, framework yok: `index.html` içinde HTML, CSS ve biraz JavaScript; Vite ile build edilip Vercel'de yayınlanıyor.

```bash
npm install
npm run dev     # geliştirme sunucusu
npm run build   # dist/ klasörüne çıktı
```

Görseller `public/img/` altında, profil fotoğrafı `public/profil.jpg`.
